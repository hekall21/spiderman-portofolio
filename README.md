## 🌟 Fitur Utama Portofolio

- 🪐 **Interactive 3D WebGL Multiverse Core (`SpiderHolo3D`):** Model 3D interaktif berbasis Three.js yang dapat diputar 360° dengan sentuhan jari (*mobile touch*) atau kursor mouse dengan akselerasi *lerp smoothing*.
- 📱 **Zero-Lag Mobile Architecture (60 FPS):**
  - **Capped DPR (1.5 max):** Menghilangkan *frame drops* pada layar AMOLED/Retina smartphone.
  - **IntersectionObserver Auto-Pause:** Menghentikan loop render saat canvas di luar viewport untuk menghemat 100% baterai & GPU ponsel.
  - **Passive Touch Listeners:** Scrolling halaman tetap sangat mulus di iPhone maupun Android.
- 🚀 **Multiverse Web & 3D Spatial Labs (12 Proyek Deployed):**
  - *Spatial Noir Photo & Video Gallery* (Michael Gatt 2.5D spatial physics & 1-click 4K downloader)
  - *Mockup 3D Studio* (Interactive 3D MacBook mockup generator)
  - *Quantum Particle Wave 3D* (10,000 GPU instanced quantum wave particles)
  - *Kinetic Typography Cube 3D* (Produx Studio editorial 3D rotating cube)
  - *Linear Command Vault* (Enterprise neo-dark task board with Cmd+K palette)
  - Dan 7 proyek web canggih lainnya!
- 🕸️ **Spider-Sense Cyberpunk Visuals:** Corner crosshairs (`+`), audio soundscape, hanging Spider-Man web-swing animation, dan typewriter mission role HUD.
- 📝 **Spider-Board Sticky Notes:** Papan pesan pengunjung berbasis Google Apps Script serverless real-time dengan RAM cache 50ms.
- 📡 **Spider-Comms Hub:** Pengiriman pesan instan satu klik via WhatsApp dan Email.
